# HOME Menu artwork

`banner.png` uses the original PC frontend logo from
`art/frontend/scrooby2/resource/images/gamelogo.png`. The original artwork is
cropped to its logo area, scaled without changing its proportions and centered
on the 256×128 HOME Menu banner.

`icon.png` is a 48×48 conversion of the existing `SRR2.jpg` game logo. The logo
artwork is not redrawn. `banner.wav` is a short silent HOME Menu sound.
