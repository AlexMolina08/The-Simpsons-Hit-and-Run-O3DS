Conversion tools

The website contains the runtime and processing tools. It does not contain the PC game's assets.

Source downloads include the exact code, local changes, build recipes and component notices used for the distributed tools.

  • Packaging and texture tools source
    makerom, bannertool, the ETC1 encoder and native texture converter.
  • FFmpeg source
    The movie and sound converter, including the Xbox audio correction.
  • FreeArc extraction source
    The archive decoder used for supported ISO installers.
  • Pyodide source and Pillow source
    The Python runtime and image-processing library.
