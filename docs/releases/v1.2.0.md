# The Simpsons: Hit & Run 3DS v1.2.0

- Improved performance and smoother world loading across all seven levels, greatly reducing missing scenery and pop-in during fast driving.
- Sharper 800×240 Quality Mode, improved lighting, character shading, vehicle reflections and HUD artwork.
- Enhanced stereoscopic 3D, steadier camera depth and corrected fog.
- Fixes for mission restarts, level transitions, delayed characters and parked-car vibration.
- Correct intro-video borders in 2D/3D, scrollable mission selection with controller and touch, and improved loading audio scheduling.

800×240 applies to supported models in 2D; stereo uses 400×240 per eye. Original 2DS stays at 400×240. Performance varies by scene.

Build with the [browser builder](https://alexmolina08.github.io/The-Simpsons-Hit-and-Run-O3DS/) using your own PC copy, then install with FBI. Before updating, back up `sd:/3ds/simpsons/` and install over the existing title without uninstalling it.

English, French and Spanish supported.
